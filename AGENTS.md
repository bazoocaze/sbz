## Conventions

- Read this file before any work.
- Concise commit messages.
- Concise comments, max 1 line.
- Only commit/push when user asks.

## Rules

- Don't bump version without explicit "make release".
- Don't create github tags or releases.

- Make release: bump patch version, update docs, commit, push. Commit message: "vN.N.N: message".
